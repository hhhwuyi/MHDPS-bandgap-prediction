This repository contains all datasets used in this study, including the regression dataset (perovskites - R.csv), the classification dataset (perovskites - C.csv), and the unknown materials screening dataset (4373.csv). It also includes three core Python scripts, namely Regression model.py (for bandgap value regression model training), Classification model.py (for bandgap type classification model training), and Materials prediction.py (for unknown materials prediction). Additional codes (for figure generation, SHAP analysis, Pearson correlation coefficient screening, feature construction, etc.) as well as DFT calculation files are available upon request.
